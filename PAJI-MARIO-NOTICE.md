# Paji Mario

This game uses **karol-f/FullScreenMario** as its gameplay base. The upstream README states that FullScreenMario is released under an Attribution Non-Commercial Share-Alike license.

Changes in this build:
- Paji character visual using the provided `malab-face.jpg`.
- Koopa/turtle visual replaced by a notebook villain.
- Bowser visual replaced by a pencil villain.
- FullScreenMario gameplay systems, maps, physics, power-ups, enemies, random-world generation, level editor, and gamepad support retained.

Upstream project: https://github.com/karol-f/FullScreenMario
